# Distribution & install strategy

## Context

Before this ADR the project had **zero release primitives**: no git tags, no
CI, a `docker-compose.yml` that ships only the legacy `/ask` stack, and —
worst — **no way to run the engine from an installed wheel**: the only server
entrypoint was `scripts/trigger_server.py` (not shipped in the wheel, and
broken since the builtins restructure — it imported `cairn.packs.incident`).
A fresh `uv sync` did not produce a working environment because several
runtime imports were never declared (`python-frontmatter`, `apscheduler`,
`temporalio`) and `fastembed`'s `onnxruntime` dependency has no recent wheels
for macOS-x86_64.

Constraint carried as an **open question**: the product name is undecided
(GitHub repo `packd`, package `cairn`). Renaming after a public release is
far more expensive than before it, so **nothing public is published until the
name is settled**. All work below is name-agnostic.

## Decision: three channels, staged by consumer

| Channel | Status | What it is |
|---|---|---|
| **A — clone + `uv sync`** | **NOW (this ADR makes it true)** | The dev/pilot channel. A fresh clone + `uv sync --extra dev` must produce a working env and a green suite; CI enforces it on every push. `uv` resolves the workspace, so a git-ref install also works for uv users. |
| **B — PyPI** | **DORMANT** (blocked on name) | Publishing the engine means publishing **all workspace wheels** (root + every operator pack) — the root depends on `operator-*` wheels that only exist on PyPI once we put them there. The release workflow builds everything and the publish step exists but is disabled until the name decision + name-availability check. |
| **C — OCI image** | **NEXT (wave item 4)** | The "self-hosted" value-prop's real consumption form: an engine image running the trigger server, built on tag. Image name blocked on the name decision; build stage is not. |

## Decision: versioning & releases

- **Lockstep versioning**: the engine and all first-party operator wheels share
  one version, released together on one tag (`v0.1.0` style). Independent
  operator versioning is a registry-era concern (parked with the registry).
- **Tags drive releases**: pushing `v*` runs the release workflow — builds all
  workspace wheels (`uv build --all-packages`), attaches them to a GitHub
  Release. The PyPI step ships disabled (`if: false` + comment pointing here).
- **CI is the gate**: tag only on a green `main`. CI runs the fresh-sync
  install path + full suite + `audit_status.py` (the docs-honesty gate).

## Decision: the serve entrypoint

The engine must be runnable from an installed wheel. The CLI verb list is
**LOCKED at 10** (ADR-0020 §24.20.14) and `serve` is not one of them — rather
than amend a locked surface, we ship a **second console script**:

```toml
[project.scripts]
cairn        = "cairn.cli.main:app"          # the 10 locked verbs
cairn-server = "cairn.core.triggers.main:main"  # the trigger server
```

`cairn/core/triggers/main.py` is pack-neutral: `Runner()` self-assembles
from entry-point pack discovery; pack-contributed `ExecutorDescriptor`s are
wired generically; default notifiers attach; `OBS_BACKEND=mock` remains the
zero-config default. `scripts/trigger_server.py` becomes a thin delegate
(it had silently broken — its incident-pack import predated the builtins
restructure; the new module is what CI can actually exercise).

## What this rejects

- **Publishing to PyPI now** — no external consumer, name undecided.
- **Helm/K8s charts** — build-ahead-of-consumer; revisit with a real deployment.
- **Independent per-wheel versioning / a resolver** — registry-era (ADR-0027
  taxonomy; registry+signing is parked north-star).
- **A new `serve` CLI verb** — would break the §24.20.14 lock for something a
  second console script does cleanly.

## Open questions

- **Product name** (user decision pending) — gates: PyPI name check + publish
  enable + public image name. Tracked in memory + here; everything else
  proceeds name-agnostic.
- PyPI name availability for `cairn` — check when the name discussion opens.
