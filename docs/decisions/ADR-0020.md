### 24.20 Pack contract — LOCKED schema, concepts, bindings, CLI surface

**Status: LOCKED.** This section is the authoritative contract for
domain packs and operator packs. Subsequent §24.x decisions reference
back here. Changes to the surfaces below require a new §24.x decision,
not edits in place — the lock is the point.

The lock matters because every author of every future pack — domain or
operator — encodes against this surface. Soft surfaces decay; locked
surfaces buy years of compatibility. The cost of locking is one design
session of careful negotiation. The cost of NOT locking is re-litigating
every detail in every PR.

#### 24.20.0 Governing principle

**Domain pack author writes intent. Operator pack author writes
implementation. Core does everything else — and the boundary is binary.**

Test for any proposed field:
- Can a non-Python developer review it in a PR? → domain pack
- Does it require knowing Temporal / Kubernetes / Docker? → push to deploy config or operator pack
- Is there one obvious way to express it? → lock it. Two ways = drop one.

#### 24.20.1 Mental model — 7 + 5 concepts (LOCKED)

Domain pack author understands **7 mandatory + 2 optional** concepts:

| # | Concept | File | Role |
|---|---|---|---|
| 1 | **Pack** | `pack.toml` | Identity + deps |
| 2 | **Template** | `templates/*.md` | Workflow graph (markdown + YAML frontmatter) |
| 3 | **Operation binding** | `operations/*.yaml` | "Use THIS operator with THIS state wiring" |
| 4 | **Schema** | `schemas/*.schema.yaml` | JSON Schema for inputs/outputs. NO Python. |
| 5 | **Policy** | `policies/*.yaml` | Budget caps / approval rules / safety thresholds |
| 6 | **Eval** | `evals/*.jsonl` | Test cases + thresholds |
| 7 | **Example** | `examples/*.json` | Input fixtures |
| 8 | **Skill** (opt) | `skills/*.md` | Auto-trigger (cron / webhook / cascade) |
| 9 | **Memory** (opt) | `memory/stores.yaml` | Cross-run memory (Reflexion) |

Operator pack author understands **5 concepts**:

| # | Concept | File | Role |
|---|---|---|---|
| 1 | **Pack** | `pack.toml` + `pyproject.toml` | Identity + Python deps |
| 2 | **Operator** | `operators/*.py` | `Operation` subclass with `run(inp, ctx)` |
| 3 | **Schema** | `schemas/*.py` | Pydantic models — source of truth |
| 4 | **Image** | `images/Dockerfile.<name>` | Container declaration (if external execution) |
| 5 | **Tests** | `tests/test_*.py` | Real test suite |

#### 24.20.2 File structures (LOCKED)

**Domain pack** — zero `.py`, zero shell, zero Dockerfiles, zero `code/`:

```
<domain-pack-name>/
├── pack.toml                    # MANDATORY
├── README.md                    # MANDATORY
├── templates/                   # MANDATORY (≥1)
│   └── <name>.md
├── operations/                  # MANDATORY (one per operation node)
│   └── <name>.yaml
├── schemas/                     # MANDATORY (input + output for entry templates)
│   └── <name>.schema.yaml
├── policies/                    # optional
├── evals/                       # optional (strongly encouraged)
├── examples/                    # optional (strongly encouraged)
├── skills/                      # optional
├── memory/                      # optional
└── triggers/                    # optional
```

Doctor-enforced: zero `.py` files anywhere in a domain pack. Period.

**Operator pack** — Python is the point:

```
<operator-pack-name>/
├── pack.toml                    # MANDATORY
├── pyproject.toml               # MANDATORY
├── README.md                    # MANDATORY
├── operators/                   # MANDATORY (≥1)
│   └── <name>.py
├── schemas/                     # MANDATORY
│   └── <name>.py                # Pydantic models
├── images/                      # optional (if operator declares image:)
└── tests/                       # MANDATORY
    ├── test_<operator>.py
    └── fixtures/
```

#### 24.20.3 Domain `pack.toml` (LOCKED — 7 top-level tables)

```toml
[pack]
name        = "<kebab-case>"      # required
version     = "0.1.0"             # required, semver
type        = "domain"            # required, literal "domain"
description = "..."               # optional
tags        = ["..."]             # optional

[compat]
cairn_engine = ">= 0.4"        # required, SpecifierSet

[assets]                          # optional — all default to dir-name match
templates  = "templates"
operations = "operations"
schemas    = "schemas"
policies   = "policies"
evals      = "evals"
examples   = "examples"
skills     = "skills"
memory     = "memory"
triggers   = "triggers"

[requires.operators]              # operator-pack-name = SpecifierSet
"operator-<name>" = ">= 0.x, < 1.0"

[requires.capabilities]           # abstract capabilities (string lists, not booleans)
required = ["model.download", "training.finetune"]
optional = ["model.register"]

[requires.services]               # abstract services bound by deploy profile
required = ["object_storage", "notifier", "secrets"]

[provides]                        # what this pack exposes (§24.3)
templates = ["..."]
events    = ["..."]

[defaults]                        # pack-level defaults (overridable per-binding)
execution_profile = "default"
artifact_store    = "default"
approval_channel  = "slack:#default"
```

Lock at **7 tables** (`pack`, `compat`, `assets`, `requires`, `provides`, `defaults`).

#### 24.20.4 Operator `pack.toml` (LOCKED)

```toml
[pack]
name        = "operator-<name>"   # required
version     = "0.3.1"             # required
type        = "operator"          # required, literal "operator"
description = "..."

[compat]
cairn_engine = ">= 0.4"

# One [operator."<name>"] table per operation this pack exposes.
[operator."<pack>/<op-name>"]
version       = "0.3.1"
input_schema  = "InputClassName"   # Python class in schemas/
output_schema = "OutputClassName"
image         = "ghcr.io/.../<op>:<ver>"  # optional — absent = inline

long_running       = true          # default false
requires_gpu       = true          # default false
supports_cancel    = false         # default false
supports_heartbeat = true          # default false
supports_mock      = true          # DX hint, NOT protocol-required

executors = ["kubernetes_job", "docker", "modal"]

[operator."<pack>/<op-name>".resources]
min_gpu_memory_gb = 40
min_memory_gb     = 64
min_disk_gb       = 200

[operator."<pack>/<op-name>".capabilities]
provides = ["<capability.name>", ...]
```

Per operator: **6 booleans + image + 2 schemas + executors + resources + capabilities**. Lock — new flags require §24.x.

#### 24.20.5 Operation binding YAML (LOCKED — 10 top-level fields)

The central file for domain authors. Maximum complete shape:

```yaml
# REQUIRED
operator: <operator-pack>/<operator-name>
version:  ">= 0.x"                            # optional, defaults to manifest range

# REQUIRED IF OPERATOR DECLARES SCHEMAS
input:
  <field>: <binding>                          # see §24.20.6 grammar
output:
  <field>: $state.<path>

# OPTIONAL — defaults provided
resources:
  cpu: 8
  memory_gb: 64
  gpu: 1
  gpu_type: A100
  disk_gb: 200
  timeout_minutes: 240

secrets: [HF_TOKEN, WANDB_API_KEY]

artifacts:
  collect: [adapter_uri, logs_uri, checkpoints_uri]

budget:
  max_cost_usd:       80
  estimated_cost_usd: 50

approval:                                     # EXPLICIT — never auto-inferred
  required: true
  reason:   "Paid GPU training"
  channel:  slack:#ml-ops-approvals
  timeout_hours: 24

policy:
  apply: [budget-cap, data-residency]

execution:
  profile: gpu-training                       # references deploy-time profile
  mode:    auto                               # default — compiler infers
```

**Top-level fields: exactly 10.** Mandatory: `operator`, `input`. Lock.

#### 24.20.6 Binding grammar (LOCKED — 6 forms + literals)

**Allowed:**

| Form | Meaning |
|---|---|
| `$input.<dotted.path>` | Read from template's input schema |
| `$state.<dotted.path>` | Read/write graph state (write-only in `output:`) |
| `$nodes.<node>.output.<dotted.path>` | Read from a prior node's output |
| `$artifacts.<artifact_name>` | Reference an artifact-store path (managed by core) |
| `$env.<NAME>` | Read deploy-time env var |
| `$default(<binding>, <literal>)` | Default if binding resolves to null |

**Literals:** `"string"`, `42`, `0.0002`, `true`, `false`, `null`, `[..]`, `{..}`.

**Forbidden (doctor rejects with file:line):**
- Jinja: `{{ x }}`, `{% if %}`
- Python expressions: `f"{x}"`, `x if y else z`, comprehensions
- String concat: `"a" + "b"`
- Method calls: `x.upper()`
- Function calls other than `$default`

#### 24.20.7 Template frontmatter (LOCKED — 9 keys)

```yaml
---
name:    <pack-name>/<template-name>          # required
version: 0.1.0                                # required

input_schema:  schema://<pack>/<SchemaName>   # required
output_schema: schema://<pack>/<SchemaName>   # required
state_schema:  schema://<pack>/<SchemaName>   # optional (state_machine flows)

runtime: auto                                 # default auto; or inprocess|temporal|restate

budget:                                       # optional
  max_cost_usd:  100
  hard_stop_usd: 120

execution:                                    # optional
  profile: <profile-name>

graph:
  start: <node>
  nodes:
    <node>:
      type: <node_type>                       # one of the 10 types in §24.20.8
      # type-specific fields
      next: <node>                            # or branch list
---

# Free-form Markdown body — part of template_hash (§24.11.3)
```

Lock at **9 frontmatter keys**.

#### 24.20.8 Universal node types (LOCKED — 10 active + 2 terminals + 2 deprecated)

| # | `type` | Required fields | Replaces / aligns with |
|---|---|---|---|
| 1 | `operation` | `ref` (→ operations/<name>.yaml), `next` | new in §24.19 |
| 2 | `agent` | `model`, `tools`, `max_iterations`, `next` | renames `agent_loop` flow type |
| 3 | `prompt` | `model`, `system`, `output_schema`, `next` | aligns with `prompt` flow |
| 4 | `approval` | `channel`, `timeout_hours`, `next`, `on_deny`, `on_timeout` | §24.14 C4 |
| 5 | `policy_gate` | `policies`, `next`, `on_fail` | renames `guard` |
| 6 | `eval_gate` | `thresholds: {field: "op value"}`, `next`, `on_fail` | new |
| 7 | `parallel` | `branches: [node, ...]`, `join: <node>` | renames `fan_out`/`fan_in` (#89) |
| 8 | `condition` | `branches: [{when, next}, ..., {default}]` | renames `selector` |
| 9 | `cleanup` | `compensate: <operation-ref>`, `next` | §24.14 C5 — new |
| 10 | `subgraph` | `template: <pack>/<name>`, `inputs`, `outputs`, `next` | existing (P2.e) |

Terminals: `END` (success), `FAIL` (failure).

Deprecated (kept for backward compat, doctor warns on new use):
- `python_node` — write an operator instead
- `tool_call` — alias for `operation` with implicit binding

Lock: **10 + 2 + 2**. New node types require §24.x.

#### 24.20.12 Operator Protocol — Python signature (LOCKED)

```python
from cairn.core.operator import Operation, OperationContext, register_operator
from .schemas import FinetuneInput, FinetuneOutput

@register_operator(
    name="unsloth/finetune_sft",
    version="0.3.1",
    capabilities=["training.finetune"],
)
class FinetuneSftOp(Operation[FinetuneInput, FinetuneOutput]):
    input_schema  = FinetuneInput
    output_schema = FinetuneOutput

    # Class-level — mirror pack.toml
    long_running        = True
    requires_gpu        = True
    supports_cancel     = False
    supports_heartbeat  = True
    supports_mock       = True
    image               = "ghcr.io/.../operator-unsloth:0.3.1"

    def run(self, inp: FinetuneInput, ctx: OperationContext) -> FinetuneOutput: ...
    def mock(self, inp: FinetuneInput, ctx: OperationContext) -> FinetuneOutput: ...   # if supports_mock
    def cancel(self, ctx: OperationContext) -> None: ...                                 # if supports_cancel
    def heartbeat(self, ctx: OperationContext) -> dict: ...                              # if supports_heartbeat
```

**Methods: 1 required (`run`) + 3 optional. Class declarations: 6 + image.** Lock.

#### 24.20.13 `OperationContext` surface (LOCKED)

Strictly bounded. Operator is a **pure leaf** — no graph awareness.

```python
class OperationContext:
    # Identity
    pipeline_id: str
    node_name:   str
    is_mocked:   bool

    # Capabilities exposed to the operator
    artifacts: ArtifactStore     # .put(name, ref) / .get(name)
    secrets:   SecretStore       # .get(name) — only those declared in binding
    metrics:   MetricsLogger     # .log(key, value)
    cost:      CostLedger        # .charge(usd, reason)
    logger:    Logger

    # Long-running helpers (only if declared)
    def emit_heartbeat(self, status: dict) -> None: ...
    def check_cancelled(self) -> bool: ...
```

**NOT in context (locked OUT):**
- Reading other nodes' outputs
- Reading graph state outside `inp`
- Modifying the graph
- Spawning other operators
- Direct runtime access (Temporal, Restate, K8s)
- Network access to other operators

Binding YAML resolves all reads at compile time; only the resolved
value reaches the operator. **This is the boundary that keeps replay
honest.**

#### 24.20.15 Execution profiles (LOCKED — deploy config, not packs)

Lives in deploy config (e.g., `~/.cairn/config.yaml` or env file):

```yaml
execution_profiles:
  default:
    runtime: inprocess
    executor: inline

  gpu-training:
    runtime: temporal
    executor: kubernetes_job
    task_queue: gpu-jobs
    artifact_store: s3
    metrics: prometheus
    timeout_minutes: 240
    retry:
      max_attempts: 3
```

Domain pack carries `execution.profile: gpu-training`; deploy config
maps the name. **Same pack runs unchanged across local / staging /
customer-VPC.**

#### 24.20.16 `runtime: auto` inference rules (LOCKED — 5 rules)

When `runtime: auto`, compiler picks:

| Operator/template declares | Compiler picks |
|---|---|
| `long_running = true` OR template duration > 5 min | `temporal` |
| `requires_gpu = true` | `temporal` + external executor |
| Uses `$artifacts.*` in any binding | Requires artifact-store binding in profile |
| Uses `secrets:` in any binding | Requires secrets binding in profile |
| Template has `approval` node | Requires notifier binding in profile |
| Nothing of the above | `inprocess` |

**Approval is NEVER auto-injected.** Operator metadata can SUGGEST
adding one (doctor: *"operator unsloth/finetune is paid_compute; consider
adding an approval before it"*) — author decides.

Lock: **5 rules.** New rules require §24.x.

#### 24.20.17 Layered validation (LOCKED — 7 levels)

`cairn validate <pack>` runs in order, stops on first failure:

| Level | Check |
|---|---|
| 1 | File structure valid (mandatory files present, no forbidden files) |
| 2 | YAML / TOML / JSON syntax valid |
| 3 | Operator refs resolve to registered operators |
| 4 | Binding inputs/outputs match operator's JSON Schema |
| 5 | Required secrets / resources / capabilities declared |
| 6 | Policies and approvals satisfied (referenced policies exist) |
| 7 | Dry-run execution plan valid (runtime selected, profile binds) |

Errors must point at `file:line` with suggested fix:

```
operations/train.yaml: input.learning_rate (line 14)
Expected number, got string "fast"

Suggested fix:
  learning_rate: 0.0002
```

#### 24.20.18 Explicitly locked OUT (do not propose)

| Feature | Why rejected |
|---|---|
| Inline JSON Schema in template frontmatter (vs `schema://` ref) | One way: file in `schemas/`. Two ways = confusion. |
| Python expression escape hatch (`!python "..."`) | Soft boundary decay. Use `$default` or add an operator. |
| Per-pack execution-profile overrides | Profile is deploy concern. Domain pack stays portable. |
| Operator hooks (`pre_run`, `post_run`, `on_retry`) | Hooks invite custom code; compose at template layer. |
| Nested operator calls (operator A calls operator B inside `run()`) | Breaks audit. Operators are leaves; composition at template. |
| Auto-inject approval gates from capability tags | Implicit graph mutation; hostile to replay. Approval = explicit. |
| Mock mode mandatory in protocol | Encouraged + doctor-warned, not required. |
| Two schema formats in domain packs (Pydantic + JSON Schema) | One way: JSON Schema YAML. Pydantic = operator packs only. |
| `python_node` in NEW templates | Deprecated; doctor warns. Backward compat for existing only. |
| Custom JSON Schema keywords | Standard draft 2020-12 only. Push complexity into Pydantic. |
| Deploy-time profile inside domain pack | Stays in deploy config. |
| Floating operator versions ("latest") | Lockfile pins. No floating in production. |
| Variadic operator calls (`operator: [a, b, c]`) | Compose as `parallel` nodes at template layer. |
| Subgraph that takes a callable parameter | Pass data only. Composition = templates. |

#### 24.20.19 Decision matrix — who owns what

| Concern | Decided by | Where |
|---|---|---|
| Which operator to call | Domain author | Binding `operator:` |
| What inputs the operator gets | Domain author | Binding `input:` |
| GPU/CPU/memory needs | Operator + domain override | Operator pack `[resources]` + binding `resources:` |
| Long-running classification | Operator author | Operator class `long_running = True` |
| Runtime (Temporal vs in-process) | Compiler | Inferred via §24.20.16 rules |
| Executor (K8s job vs Docker vs Modal) | Deploy profile | `execution_profiles.<name>.executor` |
| Container image | Operator author | Operator class `image = "..."` |
| Secrets to inject | Domain declares; profile provides | Binding `secrets:` + profile bindings |
| Retry / backoff | Deploy profile | `execution_profiles.<name>.retry` |
| Approval before run | Domain author | Explicit `approval` node |
| Budget cap | Domain / policy | Binding `budget:` + `policies/budget-cap.yaml` |
| Cost projection | Operator (estimator) + compiler aggregation | Operator method + run ledger |
| Artifact tracking | Operator declares; domain says what to collect | Binding `artifacts.collect:` |
| Replay event shape | Core | §24.14 C8 |

#### 24.20.22 What this section closes

- "How do we keep the pack surface simple without sacrificing
  capability?" — answered by locking at ~50 surface things, with
  explicit rejection of escape hatches that decay
- "Will the schema fragment across domains?" — no: domain pack surface
  is universal (incident, code-review, ModelOps, security, etc. all use
  the same 7 concepts + 10 node types); only operator names and schemas
  change per domain
- "How do non-Python authors review packs?" — every author-facing file
  is YAML/Markdown/JSON; zero Python in domain packs; doctor lints
- "How do we keep packs portable across environments?" — execution
  profiles live in deploy config; same pack runs unchanged in local /
  staging / customer VPC
- "What stops the boundary from decaying?" — §24.20.18 names the
  forbidden patterns; doctor enforces them; new §24.x required to
  change the contract
