### 24.7 Open questions (decisions deferred)

| Question | Owner | Why deferred |
|---|---|---|
| Dynamic-graph generation (planner emits TemplateSpec → compile → run) | Product | **Superseded by §24.18** — bounded dynamic-plan flow type approved with five-constraint contract; open dynamic-graph generation permanently rejected. Build trigger: open-ended-task packs (see §24.18.7 use-case table). |
| Unified `ToolContext` injected as first param of every tool (auth, run_id, memory handle) | Eng | Improves ergonomics; not blocking. Pattern can be layered on `tool_descriptors()` without engine changes. |
| User/role-based access control (who can run which pack) | Product/Sec | Identity layer needed first. Tracked under Steal-1 (credential proxy) already. |
| Unified `VerificationEngine` orchestrating static validate + citation + self-critique | Eng | Pieces work today at their own seams; orchestrator is polish. |
| `SubagentOrchestrator` class consolidating cascade + subgraph + fan-out + dispatcher concurrency | Eng | Patterns work today; abstraction is naming, not capability. |
