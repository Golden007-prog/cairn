### 24.21 Demo 2 — pack restructure showcase (NEAR-TERM EXECUTION PLAN)

**Status: scheduled.** This section replaces the original D-task demo
plan (D1–D10, #145–#155) with a restructure-showcase demo. The original
PagerDuty-driven D-task demo is **superseded**; tasks listed in §24.21.6
are cancelled.

#### 24.21.1 Demo narrative

"Three templates running on four operator packs, composed via subgraph,
all from a domain pack with **zero Python**, JSON Schema YAML for I/O,
operations as declarative bindings — and the existing tested code from
the old incident pack lives on inside the operator packs unchanged."

End state shown live in the recording: `cairn run
incident/orchestrated-incident --input examples/sample-alert.json` →
state flows through subgraph composition → three template hops →
operators invoked at each → final RCA + postmortem written to file.
