# Locked architecture (2026-06-10)

Architectural decisions agreed in the 2026-06-10 design session. These constrain every future build slice; deviation is a bug unless the user explicitly relaxes a rule.

## 1. The three-layer model is non-negotiable

```text
PACK     semantic intent — what shapes / access patterns / retention / logical names
PROFILE  technology choices — backend operators, MCP servers, embedder, runtime, defaults
ENV      glue — which profile applies, auth source, per-env overrides
```

- Pack reads the same on every stack. Profile changes per stack. Env applies a profile + supplies auth.
- Packs are **infra-free**: no `kind = "vector"`, no `backend = "pgvector"`, no URLs, no credentials. Pack declares semantic shape only.
- Already shipped: `[requires.capabilities]`, `[requires.mcp]`, `[requires.memory.<n>]`, `[requires.artifacts.<n>]`, `[requires.rag.<n>]` typed sub-tables. `[requires].services` flat list is **dead**.

## 2. Core owns interfaces; providers ship implementations

```text
Core service        = stable platform capability/interface + cross-cutting logic
Operator/adapter    = concrete implementation/provider
```

What stays in `cairn/services/`:

| Service | Keeps | Moves out to operator packs |
|---|---|---|
| LLM | router, usage tracking, budget checks, prompt normalization, structured output validation, replay events | OpenAI, Anthropic, Bedrock, Gemini, Bifrost HTTP clients |
| MCP | gateway interface, tool schema normalization, policy checks, replay, capability-to-tool resolution | specific server configs, Activepieces impl, Slack/GitHub MCP mappings |
| Memory | API, governance, read/write policy, retention, tenant isolation, redaction | pgvector, Chroma, Qdrant, Mem0, Redis implementations |
| Artifacts | model, lineage, digest/hash, sensitivity labels, retention, URI abstraction | S3, MinIO, GCS, Azure Blob clients (tiny FS impl stays as dev built-in) |
| RAG | interface, document/chunk model, citation validation, retrieval contract, ranking interface | Confluence/Notion/GitHub doc loaders, vector stores, embedding providers, rerankers |

`cairn/integrations/` and `cairn/core/storage/` follow the same rule: low-level adapter code stays as the library layer; operator packs wrap them.

## 3. All operators share one packaging contract

Same shape regardless of tier. Only **trust, distribution, signing, install policy, sandboxing** differ.

```text
operator-<name>/
  pyproject.toml
  src/operator_<name>/
    operators/        typed operations
    schemas/          input + output Pydantic models
    triggers/         if the same external system fires events
    provider.py
    auth.py
  tests/  examples/  docs/
  pack.toml + README + CHANGELOG + LICENSE
```

Every operator manifest must declare:

```toml
[pack]
name         = "operator-<name>"
version      = "..."
type         = "operator"
kind         = "operator"          # or "service_provider"
publisher    = "agentops"          # or "community/<user>", "private/<org>"
trust_level  = "official"          # builtin | official | community | private | local

[operator."<pack>/<op-name>"]
capabilities = ["<dotted>"]
input_schema = "<module>:<class>"
output_schema = "<module>:<class>"
handler      = "<module>:<class>"
executors    = ["in_process", "mcp_tool", ...]
risk         = "read_only" | "external_write" | "production_mutation" | "paid_compute"

# For mutations:
requires_approval    = true|false
supports_dry_run     = true|false
supports_verify      = true|false
supports_compensate  = true|false
```

## 4. Tier rules

| Tier | Role | Auto-install | Production allowed |
|---|---|---|---|
| **builtin** | makes local-dev work; ships with core | yes | yes |
| **official** | maintained by AgentOps; production providers | no | yes |
| **community** | third-party | no, explicit trust prompt | gated by policy |
| **private** | org-internal | no, git/path install | per org policy |
| **local** | dev-only | linked | no (unless allowlisted) |

Built-ins list (the "makes it run out of the box" set):
```
operator-core
operator-mcp                  (universal mcp/call)
operator-artifact-local
operator-memory-local         (sqlite-vector)
operator-rag-local            (sqlite-bm25)
operator-llm-mock
operator-eval-basic
operator-policy
operator-approval
operator-http
operator-scheduler
```

Built-ins **must not** carry heavy provider SDKs or surprise network side effects.

## 5. Service providers are operator packs with `kind = "service_provider"`

Same packaging contract; different role. They back the substrate's service interfaces (LLM, MCP, memory, artifact, RAG) rather than executing workflow nodes. Substrate wires them via `services.<kind>.provider:` (not `bindings.<capability>:`).

Example:
```yaml
services:
  llm:           { provider: bifrost }
  artifact_store:{ provider: s3 }
  memory:        { provider: pgvector }
  rag:           { vector_store: qdrant, embedding_provider: openai }
```

## 6. Triggers — domain pack declares, provider implements, core routes

```text
External system → Trigger provider (in operator pack) → Event normalizer
              → Core trigger router → Domain pack trigger YAML → Workflow run
```

- Domain pack ships `triggers/*.yaml` (intent + matching rules only).
- Trigger receiver code (signature verification, payload normalization) lives in the matching operator pack (`operator-github/triggers/pull_request.py`).
- FastAPI is **generic ingress** — verify signature via provider, normalize event, hand to core router. Never hardcode "if pagerduty then run incident-rca".

## 7. Actions = operators + executors. No parallel "action" layer.

```text
Action  = risky/mutating operation
Operator = typed operation contract (what)
Executor = how the operator runs (where/how)
```

Executor enum (locked):
```
in_process | mcp_tool | docker | kubernetes_job | temporal_activity | remote_job | http_call
```

Operator declares which executors it supports; core picks at run time based on env policy and the operator's risk level. MCP is **one executor option** — never the whole action system.

Mutation lifecycle hooks (when operator declares them):
`plan → dry_run → execute → verify → compensate → cleanup`

## 9. Phase 2 scope (locked)

1. **Manifest `kind` field** — `domain | operator | service_provider`. Default `operator` for an operator pack.
2. **Operator manifest** gains required fields: `capabilities`, `risk`, `executors`, optional `requires_approval`, `supports_dry_run`, `supports_verify`, `supports_compensate`.
3. **Trust + signing metadata** — `publisher`, `trust_level`, signature field. No enforcement Phase 2; doctor surfaces.
4. **Trigger provider seam** — formalize layout (`operator-<name>/triggers/`), core router subscribes, domain pack stays YAML-only.
5. **Executor enum + dispatcher** — locked enum above; substrate picks executor based on operator manifest + env policy.
6. **Five reference operators** built as thin wrappers over `cairn/services/` + `cairn/core/storage/`:
   - `operator-mcp` (universal mcp/call)
   - `operator-memory-local` (sqlite-vector)
   - `operator-artifact-local` (fs)
   - `operator-rag-local` (sqlite-bm25)
   - `operator-state-local` (sqlite)
7. **No code migration** of `services/rag/stores/qdrant.py` etc. yet — those move out to `official/operators/` in Phase 3+.

## 10. What stays put (do not refactor in Phase 2)

- `cairn/services/` — interface + cross-cutting logic layer. Stays.
- `cairn/integrations/` — low-level adapter libraries. Stays.
- `cairn/core/storage/` — substrate storage layer. Stays.
- Existing operator packs (postmortem, blast_radius, git, clickstack) — already-correct shape. Update manifests only.

## 11. Don't re-litigate

These are decided; do not re-open without an explicit request from the user:
- Capability refs are the only template-side binding form.
- Profile sits between pack and env; profiles are diff-able YAML, tier-promotable.
- Logical-name collisions resolved by per-pack aliases in env (not by per-pack scoping in pack).
- `[requires].services` flat list is dead. Sub-tables only.
- Built-ins must not carry heavy provider SDKs.
- Substrate brokers; ecosystem implements backends.
