### 24.5 Decision: eval (last of the original CLI MVP-six)

Still pending. Reuses `run`'s pipeline; per-case scoring against schemas
+ structural diff. Judge-LLM scoring deferred to v0.2.

Skeleton:

```
evals/<dataset>.jsonl   ← one row per case
  {"name": "...", "trigger": {...}, "expected": {...}}

cairn eval <pack>           # run every dataset
cairn eval <pack> --case X  # run one case
cairn eval <pack> --json    # machine-readable for CI
```

Each case produces a run_id, so `cairn replay <run-id>` on a failed
case is the debug loop.

**MVP scope**: schema-validity + structural JSON diff. No judge LLM. No
regression-against-baseline yet. ~2 days.
